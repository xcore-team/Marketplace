# xdocs

Extrait et sert la documentation (`README.md`, `INTEGRATION.md`,
`contributor.yaml`) des ZIP de plugins/services validés par le pipeline
marketplace.

## Fonctionnalités

- Extraction automatique des fichiers de doc reconnus après validation
  d'une soumission (`readme`, `integration`, `contributor`)
- Service de la documentation de la dernière version validée d'un plugin
- Service de la documentation d'une version précise

## Dépendances

| Plugin requis | Version |
|---|---|
| `marketplace` | `1.0.0` |

Détail complet des routes : [INTEGRATION.md](INTEGRATION.md).
